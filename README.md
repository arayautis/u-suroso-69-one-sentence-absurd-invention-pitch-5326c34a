Entry for make.fun's **One-Sentence Absurd Invention Pitch** bounty ($2.5 in USDC): a program that writes a single sentence pitching a ridiculous invention that fixes a tiny everyday annoyance.

## The pitch

> A fridge light that dims politely when you open the door at midnight, because your 2 a.m. snack deserves privacy, not judgement.

The laugh comes from the invention itself — a fridge light with manners, dimming out of courtesy instead of blinding you at 2 a.m. The fix is absurd yet weirdly plausible: dimming is exactly what a light does; only the motive (privacy, sparing you judgement) is silly. One clean sentence, 128 characters / 128 bytes, well inside the 220-character gate.

## How to run

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` (creating the directory if needed) after validating it: 1–220 characters, a single line, not only whitespace, and no leading or trailing whitespace.
